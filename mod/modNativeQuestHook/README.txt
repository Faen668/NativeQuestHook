Native Quest Hook
Quest block events for The Witcher 3 Remastered, in WitcherScript.

This folder holds the scripts other mods use. NativeQuestHook.asi goes in bin\x64_dx12 and needs
Ultimate ASI Loader's dinput8.dll there too. Without the .asi, mods using this still run and simply hear nothing.
